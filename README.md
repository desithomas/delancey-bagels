#  Delancey Bagels

**[View Live Deployment](https://delanceybagels.netlify.app/)**

A static, highly responsive front-end landing page for a New York-style bagel shop. This project was engineered strictly using HTML and CSS to maximize performance, prioritize Core Web Vitals, and ensure a lightweight footprint without relying on JavaScript overhead.

##  Tech Stack

* **HTML5:** Semantic architecture designed for maximum SEO visibility and screen-reader accessibility (a11y).
* **CSS3:** Advanced responsive design utilizing Flexbox/CSS Grid, media queries, and pure CSS pseudo-classes to handle UI interactions and layout shifts across all viewport sizes.
* **Deployment:** CI/CD pipeline integrated via Netlify for automated builds.
